# Data Structures Lab Assignments

This repository contains my **UCS301 Data Structures lab assignments** completed as part of my coursework.

## 📚 Assignments

### Lab Assignment 1 — Arrays

**Language:** C++

Topics covered:

* Menu-driven array operations
* Removing duplicate elements
* Array rotation
* Reversing an array
* Matrix multiplication
* Matrix transpose
* Row and column sums

### Lab Assignment 2 — Arrays Continued

**Language:** Java

Topics covered:

* Binary Search
* Bubble Sort
* Finding a missing number
* String operations
* Space-efficient matrix representation
* Sparse Matrix operations
* Counting inversions
* Counting distinct elements

### Assignment 4 — Queues

**Language:** Java

Topics:
- Simple Queue
- Circular Queue
- Queue Interleaving
- First Non-Repeating Character
- Stack Using Two Queues
- Stack Using One Queue

More lab assignments will be added as they are completed.
